Como Jogar

Adivinhe a palavra secreta em até 6 tentativas!

  • Cada tentativa deve ser uma palavra válida com a quantidade certa de letras.
  • As cores das letras mudam para mostrar o quão perto você está:
A
Verde: A letra está na palavra e na posição correta.
B
Amarelo: A letra está na palavra, mas em outra posição.
C
Cinza: A letra não faz parte da palavra.

Uma nova palavra é liberada todos os dias! Volte sempre para manter sua sequência.
